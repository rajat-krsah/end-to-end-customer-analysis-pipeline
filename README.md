# End-to-End Customer Analysis Pipeline

## Project Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, and Power BI to uncover meaningful business insights. The end-to-end analytics pipeline covers data cleaning, feature engineering, SQL-based business analysis, and interactive dashboard creation to support data-driven decision-making.

---

## Business Problem

A retail company wants to better understand customer purchasing behavior to improve customer engagement, optimize marketing strategies, and increase revenue. This project analyzes customer transaction data to identify purchasing trends, customer segments, subscription behavior, and revenue-driving factors.

---

## Objectives

- Clean and preprocess raw customer data using Python.
- Perform feature engineering for better analysis.
- Load the cleaned dataset into PostgreSQL.
- Solve business problems using SQL queries.
- Build an interactive Power BI dashboard.
- Generate actionable business recommendations.

## SQL Business Questions Solved

- Total revenue by gender
- High-spending customers using discounts
- Top-rated products
- Shipping type comparison
- Subscriber vs Non-subscriber analysis
- Discount purchase analysis
- Customer segmentation
- Top-performing products by category
- Repeat buyer analysis
- Revenue contribution by age group


---

## Key Insights

- Clothing generated the highest revenue among all product categories.
- Young Adult customers contributed the highest share of total revenue.
- Most customers were non-subscribers.
- Discount campaigns significantly influenced purchases for selected products.
- Repeat customers contributed a substantial portion of overall sales.

---

## Business Recommendations

- Increase subscription adoption through exclusive member benefits.
- Strengthen customer loyalty programs.
- Optimize discount strategies to improve profitability.
- Promote top-rated and high-performing products.
- Focus marketing efforts on high-value customer segments.
